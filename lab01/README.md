### Постановка задачи

Получить трассировки системных вызовов `cat` и ЛР2, ЛР3, ЛР4. Сгруппировать вызовы по назначению.

### Трассировка

Трассировки получены в Ubuntu 24.04 в Docker. Ключ `-f` включает трассировку дочерних процессов и потоков, `-o` записывает трейс в файл.

```bash
strace -f -o lab01/traces/cat.txt cat build/lab01-linux/cat-input.txt
strace -f -o lab01/traces/lab02.txt ./build/lab01-linux/lab02/lab02_parent
strace -f -o lab01/traces/lab03.txt ./build/lab01-linux/lab03/lab03 -t 2
strace -f -o lab01/traces/lab04.txt ./build/lab01-linux/lab04/lab04_parent
```

### Системные вызовы

| Трейс | Группа | Вызовы | Назначение |
|---|---|---|---|
| [cat](../traces/cat.txt) | Загрузка программы, файловый ввод-вывод | `execve`, `mmap`, `openat`, `fstat`, `read`, `write`, `close` | `execve` запускает `cat`. При запуске `mmap` используется для загрузки библиотеки. Затем `cat` открывает входной файл, узнаёт его размер через `fstat`, читает данные, пишет их в стандартный вывод и закрывает файл. |
| [ЛР2](../traces/lab02.txt) | Процессы, каналы | `clone`, `execve`, `wait4`, `pipe2`, `dup3`, `read`, `write` | Родитель создаёт два канала и два дочерних процесса. Через `dup3` каждый ребёнок подключает стандартный ввод к читающему концу своего канала, а стандартный вывод к выходному файлу. Затем запускается `lab02_child`, который читает строки из канала и пишет результат в файл. Родитель ждёт завершения обоих детей. |
| [ЛР3](../traces/lab03.txt) | Потоки | `clone`, `futex` | `clone` с флагом `CLONE_THREAD` создаёт рабочий поток. Главный поток ждёт его завершения через `futex`. |
| [ЛР4](../traces/lab04.txt) | Отображение файлов | `openat`, `ftruncate`, `mmap`, `msync`, `munmap` | Родитель открывает файлы, задаёт их размер и отображает с `MAP_SHARED`. Дети отображают те же файлы, синхронизируют изменения в памяти с файлами через `msync` и освобождают отображения через `munmap`. |
