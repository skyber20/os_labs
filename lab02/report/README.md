### Постановка задачи

Родительский процесс создаёт два дочерних процесса и два канала pipe.
Пользователь вводит имена двух выходных файлов, затем строки произвольной длины.
Строки длиной не более 10 символов отправляются первому ребёнку, остальные второму.
Оба дочерних процесса переворачивают полученные строки и записывают результаты в свои файлы.

### Алгоритм решения

1. Родитель считывает имена файлов и создаёт два канала с помощью `pipe`
2. Создаёт двух детей через `fork`. Каждый ребёнок открывает свой файл, настраивает `stdin` и `stdout` через `dup2` и запускает программу `lab02_child` через `execl`
3. Родитель читает строки через `getline` и по длине выбирает канал для передачи
4. Дочерние процессы читают строки, переворачивают их и выводят результат в файл
5. После окончания ввода родитель закрывает каналы и дожидается детей через `waitpid`

### Сборка и запуск

Из корня репозитория:

```bash
cmake -S . -B build
cmake --build build
./build/lab02/lab02_parent
```

Для завершения ввода строк нажать `Ctrl+D`.

### Пример работы

```text
Введите имя файла для child1: out1.txt
Введите имя файла для child2: out2.txt
Введите строки. Для завершения нажмите Ctrl+D:
hello
hello world
```

После завершения программы:

`out1.txt`:

```text
olleh
```

`out2.txt`:

```text
dlrow olleh
```

Примеры приведены для латиницы. В текущей реализации длина и разворот строк выполняются по байтам, поэтому UTF-8 кириллица обрабатывается некорректно.

### Вывод

Реализовано взаимодействие родительского и двух дочерних процессов через неименованные каналы. На практике использованы `fork`, `pipe`, `dup2`, `execl`, `open` и `waitpid`, а также обработка ошибок и закрытие файловых дескрипторов.
