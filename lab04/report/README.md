## Лабораторная работа №4

### Постановка задачи

Родительский процесс создаёт два дочерних процесса. Пользователь вводит имена двух выходных файлов и строки произвольной длины. Строки длиной не более 10 символов передаются первому ребёнку, остальные — второму. Дочерние процессы переворачивают полученные строки и сохраняют результаты в соответствующие файлы.

В отличие от лабораторной №2, взаимодействие между процессами реализовано с помощью отображённых файлов (`mmap`), а не каналов `pipe`.

### Алгоритм решения

1. Родитель считывает имена файлов и строки с помощью `getline`, распределяет строки на две группы по длине.
2. Создаёт выходные файлы через `open`, задаёт их размер через `ftruncate`, отображает в память через `mmap` с `MAP_SHARED` и записывает строки в отображённые области.
3. Создаёт двух дочерних процессов через `fork` и запускает `lab04_child` через `execl`, передавая имя соответствующего файла.
4. Каждый ребёнок открывает свой файл, отображает его через `mmap`, переворачивает строки непосредственно в отображённой памяти, сохраняя порядок строк и символы переноса.
5. Родитель ожидает завершения обоих детей через `waitpid`, затем освобождает отображения через `munmap` и выделенную память.

### Сборка и запуск

Добавить `add_subdirectory(lab04)` во внешний `CMakeLists.txt`. Затем из корня репозитория:

```bash
cmake -S . -B build
cmake --build build
./build/lab04/lab04_parent
```

Для завершения ввода строк нажать `Ctrl+D`.

### Пример работы

```text
Введите имя файла для child1: out1.txt
Введите имя файла для child2: out2.txt
Введите строки. Для завершения нажмите Ctrl+D:
hello
hello world
```

После завершения программы `out1.txt` содержит:

```text
olleh
```

`out2.txt` содержит:

```text
dlrow olleh
```

Длина и переворот выполняются по байтам, поэтому UTF-8 кириллица обрабатывается некорректно.

### Вывод

Реализовано взаимодействие родительского и двух дочерних процессов через отображённые файлы. На практике использованы `fork`, `execl`, `waitpid`, `open`, `ftruncate`, `mmap`, `msync` и `munmap`.
